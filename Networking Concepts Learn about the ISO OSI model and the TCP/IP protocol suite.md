### ISO OSI Model

ISO OSI model হলো একটা কল্পনামূলক ফ্রেমওয়ার্ক যা কম্পিউটার নেটওয়ার্কে কীভাবে যোগাযোগ হয় তা বর্ণনা করে। এটা International Organization for Standardization (ISO) দিয়ে তৈরি করা হয়েছে। এতে সাতটা লেয়ার আছে, যা নিচ থেকে উপরে গণনা করা হয়: লেয়ার ১ থেকে লেয়ার ৭। এটা শিখলে নেটওয়ার্কিংয়ের ধারণা আরও গভীরভাবে বোঝা যায়। মনে রাখার জন্য একটা সহজ মনে রাখার উপায়: “Please Do Not Throw Spinach Pizza Away” – এটা লেয়ারগুলোর নামের প্রথম অক্ষর মিলিয়ে। এখন প্রত্যেক লেয়ার আলাদাভাবে ব্যাখ্যা করছি, খুব সহজ করে।

#### Layer 1: Physical Layer
Physical Layer হলো নিচের সবচেয়ে লেয়ার, যা ডিভাইসগুলোর মধ্যে শারীরিক সংযোগ নিয়ে কাজ করে। এটা তারের মতো মাধ্যম এবং বাইনারি ডিজিট ০ আর ১ কীভাবে পাঠানো হয় তা নির্ধারণ করে। ডেটা ইলেকট্রিক্যাল, অপটিক্যাল বা ওয়্যারলেস সিগন্যাল দিয়ে পাঠানো হয়। উদাহরণ: Ethernet cable বা WiFi radio bands যেমন ২.৪ GHz, ৫ GHz। এখানে শুধু সিগন্যাল পাঠানোর মাধ্যম নিয়ে চিন্তা করা হয়, কোনো ডেটা প্রসেসিং নয়।

#### Layer 2: Data Link Layer
Data Link Layer হলো লেয়ার ২, যা একই নেটওয়ার্ক সেগমেন্টে থাকা ডিভাইসগুলোর মধ্যে ডেটা ট্রান্সফারের প্রোটোকল নিয়ে কাজ করে। সহজ কথায়, এটা একই গ্রুপের কম্পিউটারগুলো কীভাবে একে অপরের সাথে কথা বলবে তা নিয়ম করে। নেটওয়ার্ক সেগমেন্ট মানে একটা শেয়ার্ড মিডিয়ামে সংযুক্ত ডিভাইসের গ্রুপ, যেমন একটা অফিসে ১০টা কম্পিউটার সুইচ দিয়ে যুক্ত। উদাহরণ: Ethernet (802.3) বা WiFi (802.11)। এখানে MAC address ব্যবহার হয়, যা ৬ বাইটের ঠিকানা, হেক্সাডেসিমাল ফরম্যাটে লেখা। প্রত্যেক ফ্রেমে সোর্স এবং ডেসটিনেশন MAC address থাকে।

#### Layer 3: Network Layer
Network Layer হলো লেয়ার ৩, যা বিভিন্ন নেটওয়ার্কের মধ্যে ডেটা পাঠানো নিয়ে কাজ করে। এটা লজিক্যাল অ্যাড্রেসিং এবং রাউটিং করে, অর্থাৎ প্যাকেট কোন পথে যাবে তা খুঁজে বের করে। সহজ উদাহরণ: একটা কোম্পানির বিভিন্ন অফিস বিভিন্ন শহরে থাকলে, এই লেয়ার সেগুলোকে যুক্ত করে। উদাহরণ প্রোটোকল: IP, ICMP, VPN যেমন IPSec। এখানে প্যাকেট দুটো পথের মধ্যে ভালোটা বেছে নেয়।

#### Layer 4: Transport Layer
Transport Layer হলো লেয়ার ৪, যা বিভিন্ন হোস্টে চলা অ্যাপ্লিকেশনের মধ্যে শেষ থেকে শেষ যোগাযোগ করে। এটা ফ্লো কন্ট্রোল, সেগমেন্টেশন এবং এরর করেকশন করে। উদাহরণ: TCP এবং UDP। এখানে পোর্ট নম্বর ব্যবহার করে প্রসেস আইডেন্টিফাই করা হয়।

#### Layer 5: Session Layer
Session Layer হলো লেয়ার ৫, যা অ্যাপ্লিকেশনের মধ্যে সেশন স্থাপন, রক্ষণাবেক্ষণ এবং সিঙ্ক্রোনাইজেশন করে। এটা যোগাযোগ শুরু করে এবং প্যারামিটার নেগোশিয়েট করে, ডেটা অর্ডার ঠিক রাখে এবং ফেলিওর হলে রিকভারি করে। উদাহরণ: NFS, RPC।

#### Layer 6: Presentation Layer
Presentation Layer হলো লেয়ার ৬, যা ডেটা অ্যাপ্লিকেশন লেয়ারে বোঝার মতো ফরম্যাটে পৌঁছানো নিশ্চিত করে। এটা এনকোডিং, কম্প্রেশন এবং এনক্রিপশন করে। উদাহরণ: ASCII, Unicode, JPEG, MIME। যেমন ইমেইলে ছবি পাঠানোর সময় MIME ব্যবহার হয়।

#### Layer 7: Application Layer
Application Layer হলো সবচেয়ে উপরের লেয়ার ৭, যা ইউজার অ্যাপ্লিকেশনকে সরাসরি নেটওয়ার্ক সার্ভিস দেয়। উদাহরণ: HTTP দিয়ে ওয়েব ব্রাউজার ফাইল রিকোয়েস্ট করে। অন্যান্য প্রোটোকল: FTP, DNS, POP3, SMTP, IMAP। এটা ইউজারের সাথে সরাসরি যুক্ত।

### TCP/IP Model

TCP/IP Model হলো একটা বাস্তব মডেল যা Transmission Control Protocol/Internet Protocol এর উপর ভিত্তি করে, Department of Defense (DoD) দিয়ে ১৯৭০ এর দশকে তৈরি। এটা OSI মডেলের মতো নয়, এতে চারটা বা পাঁচটা লেয়ার আছে। এটা নেটওয়ার্ককে এমনভাবে ডিজাইন করা যাতে অংশবিশেষ নষ্ট হলেও কাজ চলে। উপর থেকে নিচে লেয়ারগুলো: Application Layer (OSI এর ৫,৬,৭ একসাথে), Transport Layer (OSI এর ৪), Internet Layer (OSI এর ৩), Link Layer (OSI এর ২)। কিছু বইয়ে Physical Layer যোগ করে পাঁচটা লেয়ার করে। উদাহরণ প্রোটোকল: Application – HTTP, FTP; Transport – TCP, UDP; Internet – IP, ICMP; Link – Ethernet। এটা ইন্টারনেটের ভিত্তি।

### IP Addresses and Subnets

IP Address হলো নেটওয়ার্কে প্রত্যেক ডিভাইসের ইউনিক আইডেন্টিফায়ার, যাতে অন্যরা তার সাথে যোগাযোগ করতে পারে। এটা চারটা অকটেট দিয়ে তৈরি, প্রত্যেক অকটেট ০ থেকে ২৫৫ এর মধ্যে, যেমন ১৯২.১৬৮.০.১। IPv4 সবচেয়ে কমন, যাতে প্রায় ৪ বিলিয়ন অ্যাড্রেস সম্ভব। Subnet মানে একটা গ্রুপ অ্যাড্রেস যা একই নেটওয়ার্কে, subnet mask দিয়ে নির্ধারিত, যেমন ২৫৫.২৫৫.২৫৫.০ বা /২৪। এতে নেটওয়ার্ক অ্যাড্রেস (যেমন ১৯২.১৬৮.১.০) এবং broadcast অ্যাড্রেস (১৯২.১৬৮.১.২৫৫) থাকে। Private IP ranges: ১০.০.০.০-১০.২৫৫.২৫৫.২৫৫, ১৭২.১৬.০.০-১৭২.৩১.২৫৫.২৫৫, ১৯২.১৬৮.০.০-১৯২.১৬৮.২৫৫.২৫৫ – এগুলো ইন্টারনেট থেকে অ্যাক্সেসযোগ্য নয়, NAT দিয়ে পাবলিক IP এর সাথে যুক্ত হয়। কমান্ড লাইনে দেখার জন্য: Windows এ ipconfig, Linux এ ifconfig বা ip a s।

### Routing

Routing হলো প্যাকেটকে সঠিক নেটওয়ার্কে পাঠানোর প্রক্রিয়া। Router হলো ডিভাইস যা লেয়ার ৩ এ কাজ করে, IP অ্যাড্রেস দেখে প্যাকেটকে পরবর্তী ভালো পথে পাঠায়। সহজ উদাহরণ: পোস্ট অফিসের মতো, যা মেইলকে সঠিক শহরে পাঠায়। প্যাকেট অনেক রাউটার দিয়ে যায় যতক্ষণ না গন্তব্যে পৌঁছায়। এটা নেটওয়ার্ক লেয়ারে হয়।

### UDP and TCP

UDP (User Datagram Protocol) হলো লেয়ার ৪ এর কানেকশনলেস প্রোটোকল, যা হোস্টের প্রসেসে ডেটা পাঠায় কিন্তু ডেলিভারি নিশ্চিত করে না। এটা স্পিডি, যেমন সাধারণ মেইল সার্ভিস। TCP (Transmission Control Protocol) হলো কানেকশন-ওরিয়েন্টেড, রিলায়েবল ডেলিভারি নিশ্চিত করে three-way handshake দিয়ে (SYN, SYN-ACK, ACK)। এটা সিকোয়েন্স নম্বর এবং অ্যাকনলজমেন্ট ব্যবহার করে লস্ট প্যাকেট চেক করে। উভয়ই পোর্ট নম্বর ব্যবহার করে প্রসেস আইডেন্টিফাই করে।

### Port Numbers

Port Number হলো দুই অকটেটের নম্বর, ১ থেকে ৬৫৫৩৫ পর্যন্ত (০ রিজার্ভড)। এটা হোস্টে চলা প্রসেস আইডেন্টিফাই করে, যাতে IP অ্যাড্রেস দিয়ে হোস্ট পাওয়ার পর প্রসেসে পৌঁছানো যায়। উদাহরণ: ওয়েব সার্ভার পোর্ট ৮০, daytime সার্ভার ১৩। UDP বা TCP এ ব্যবহার হয়।

### Encapsulation

Encapsulation হলো প্রত্যেক লেয়ারে ডেটাতে হেডার (কখনো ট্রেলার) যোগ করে নিচের লেয়ারে পাঠানো। সহজ কথায়: অ্যাপ্লিকেশন ডেটা থেকে শুরু করে, Transport Layer এ TCP/UDP হেডার যোগ করে সেগমেন্ট বানায়, Network Layer এ IP হেডার যোগ করে প্যাকেট, Link Layer এ Ethernet/WiFi হেডার যোগ করে ফ্রেম। রিসিভিং এন্ডে উল্টো প্রক্রিয়া হয়। এটা প্রত্যেক লেয়ারকে তার কাজে ফোকাস করতে সাহায্য করে।

### The Life of a Packet

প্যাকেটের লাইফ মানে ডেটা কীভাবে যাত্রা করে। উদাহরণ: TryHackMe সার্চ করলে – ১. ইউজার কোয়েরি ইনপুট করে। ২. ব্রাউজার HTTP রিকোয়েস্ট তৈরি করে Transport Layer এ পাঠায়। ৩. TCP কানেকশন স্থাপন করে সেগমেন্ট পাঠায় Internet Layer এ। ৪. IP হেডার যোগ করে প্যাকেট বানায়, Link Layer এ পাঠায়। ৫. Link Layer ফ্রেম বানায় রাউটারে পাঠায়। ৬. রাউটারগুলো IP দেখে ফরোয়ার্ড করে গন্তব্যে পৌঁছায়। রিসিভিং এন্ডে উল্টো।

### Telnet

Telnet হলো একটা প্রোটোকল যা রিমোট সিস্টেমে কানেক্ট করে টেক্সট কমান্ড দেয়। এটা TCP পোর্টে কানেক্ট করে। সহজ উদাহরণ: কমান্ড লাইনে telnet IP port দিয়ে কানেক্ট। যেমন echo সার্ভারে (পোর্ট ৭) কানেক্ট করে টেক্সট পাঠালে echo করে। Daytime সার্ভার (পোর্ট ১৩) সময় দেয়। HTTP সার্ভার (পোর্ট ৮০) এ GET / HTTP/1.1 দিয়ে ওয়েব পেজ রিকোয়েস্ট করা যায়। কানেকশন বন্ধ করতে CTRL + ]। এটা সিকিউর নয়, কিন্তু ওপেন TCP পোর্ট কানেক্ট করার উদাহরণ।
